# 處室網頁模組編輯器

國立宜蘭大學職涯發展中心網頁用的模組編輯器。拖拉排版、直接改文字，最後產出可以貼到網站後台「原始碼」的 HTML + CSS。

**線上使用：** 開啟 GitHub Pages 後到 `https://dot0427.github.io/niu_css_edit/`

## 檔案

| 路徑 | 說明 |
| --- | --- |
| `index.html` | 編輯器本體（單一檔案，不用安裝，直接用瀏覽器打開） |
| `pages/` | 24 個現有頁面轉成新版 `cdc-*` 命名後的程式碼，打開整段複製貼到後台 |

## 功能

- **版面模組**：標題卡片、卡片連結格、PDF 嵌入、橫幅圖片、區段標題條、成員卡片、空白間距、自訂 HTML
- **內容元件**（放在標題卡片裡）：段落、強調大字、編號項目、標籤資訊列、檔案下載列表、網站連結列表、獎助金額表、圖片、圖片連結格、按鈕、項目符號清單、分隔線
- 文字直接在畫面上改；選取文字可加粗、強調、加連結或小按鈕
- 圖片路徑可留空，輸出時放「請替換」佔位圖，到後台再選圖
- 匯入舊程式碼：貼上後台原始碼會自動拆成可編輯模組
- 產出的 CSS 只包含該頁用到的模組
- 多頁管理、復原／重做、手機預覽、4 組配色
- 資料存在瀏覽器 localStorage，換電腦前請用「頁面 ⋯ → 匯出專案檔」備份

## 貼到後台

1. 編輯器按「產出程式碼」→「複製全部」
2. 後台編輯器切到「原始碼」，全選刪掉後貼上
3. 切回來確認畫面，佔位圖點兩下換成正式圖片
